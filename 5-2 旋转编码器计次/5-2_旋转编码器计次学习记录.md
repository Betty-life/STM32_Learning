# 5-2 旋转编码器计次学习记录

## 一、实验功能

旋转编码器正转时计数加一，反转时计数减一，OLED 显示计数值。

## 二、硬件接线

| 外设 | 引脚 |
| --- | --- |
| 编码器 A 相 | PB0 |
| 编码器 B 相 | PB1 |
| OLED（SCL） | PB8 |
| OLED（SDA） | PB9 |

## 三、代码结构

### Encoder.c

```c
void Encoder_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);

    GPIO_InitTypeDef GPIO_InitStruct;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1;
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStruct);

    GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource0);
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource1);

    EXTI_InitTypeDef EXTI_InitStruct;
    EXTI_InitStruct.EXTI_Line = EXTI_Line0 | EXTI_Line1;
    EXTI_InitStruct.EXTI_LineCmd = ENABLE;
    EXTI_InitStruct.EXTI_Mode = EXTI_Mode_Interrupt;
    EXTI_InitStruct.EXTI_Trigger = EXTI_Trigger_Falling;
    EXTI_Init(&EXTI_InitStruct);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);

    NVIC_InitTypeDef NVIC_InitStruct;
    NVIC_InitStruct.NVIC_IRQChannel = EXTI0_IRQn;
    NVIC_InitStruct.NVIC_IRQChannelCmd = ENABLE;
    NVIC_InitStruct.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStruct.NVIC_IRQChannelSubPriority = 1;
    NVIC_Init(&NVIC_InitStruct);

    NVIC_InitStruct.NVIC_IRQChannel = EXTI1_IRQn;
    NVIC_InitStruct.NVIC_IRQChannelCmd = ENABLE;
    NVIC_InitStruct.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStruct.NVIC_IRQChannelSubPriority = 2;
    NVIC_Init(&NVIC_InitStruct);
}
```

### 中断服务函数

```c
void EXTI0_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line0) == SET)
    {
        if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)
        {
            Encoder_count++;
        }
        EXTI_ClearITPendingBit(EXTI_Line0);
    }
}

void EXTI1_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line1) == SET)
    {
        if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_0) == 0)
        {
            Encoder_count--;
        }
        EXTI_ClearITPendingBit(EXTI_Line1);
    }
}
```

### main.c

```c
int main(void)
{
    OLED_Init();
    Encoder_Init();

    OLED_ShowString(1, 1, "HelloWorld!");
    OLED_ShowString(2, 1, "Count:");

    while (1)
    {
        Encoder_num += EncoderCount_Get();
        OLED_ShowSignedNum(2, 8, Encoder_num, 5);  // ✅ 有符号显示
    }
}
```

> 注：`Encoder_count`（中断中计数）、`Encoder_num`、`EncoderCount_Get()` 的定义与声明未在本记录中给出，需在 Encoder.c 中补充（如 `int16_t Encoder_count;` 及读取并清零计数的函数）。

## 四、踩坑记录

### 错误 1：OLED_ShowNum 显示无符号数，负数变成 67292

**原因**：`Encoder_num` 是 `int16_t`，-1 的补码是 0xFFFF。`OLED_ShowNum` 把 0xFFFF 当作无符号数解释，溢出后显示 67292。
**正确**：改用 `OLED_ShowSignedNum(2, 8, Encoder_num, 5);`，-1 正常显示为 -0001。

### 错误 2：EXTI 线号和中断函数判断不匹配

配了 `EXTI_Line1` 却写了 `EXTI_Line12`，中断永远进不去。

### 错误 3：PB1 被板载外设占用

江协板子上 PB1 可能同时接了 LED 或按键，导致编码器信号无法拉低 PB1。换到 PB5 或 PB6 可解决。

### 错误 4：中断里调用 OLED 显示导致乱码

中断里只做计数，显示放到主循环。

### 错误 5：GPIO_ReadInputDataBit() 参数写错

第二个参数必须是 `GPIO_Pin_x`，不是 `EXTI_Line_x`。

## 五、调试方法论

### 5.1 中断不进时的排查顺序

1. AFIO 时钟是否开启
2. GPIO 模式是否配成上拉 / 下拉输入
3. `GPIO_EXTILineConfig()` 是否正确映射
4. EXTI 线号和 NVIC 通道号是否匹配
5. 中断函数名是否和启动文件一致
6. 中断标志位是否清除

### 5.2 用模拟代码隔离问题

在 `while(1)` 里手动操作 GPIO 产生边沿，绕过硬件，验证中断逻辑：

```c
while (1)
{
    GPIO_ResetBits(GPIOB, GPIO_Pin_1);
    Delay_ms(10);
    GPIO_ResetBits(GPIOB, GPIO_Pin_0);
    Delay_ms(50);
    GPIO_SetBits(GPIOB, GPIO_Pin_0);
    GPIO_SetBits(GPIOB, GPIO_Pin_1);
    Delay_ms(50);
}
```

- 模拟能跑通 → 代码没问题，问题在硬件。
- 模拟跑不通 → 代码或 EXTI 配置有问题。

### 5.3 用轮询验证引脚信号

```c
while (1)
{
    OLED_ShowNum(2, 1, GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_0), 1);
    OLED_ShowNum(3, 1, GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1), 1);
}
```

旋转时看 OLED 上电平是否变化，判断信号是否到达 STM32。

## 六、经验总结

- 引脚号、EXTI 线号、NVIC 通道号、中断函数名，四者必须完全匹配。
- 中断里只做计数，显示放到主循环。
- 模拟测试是区分"代码问题"和"硬件问题"的最快方法。
- PB1 在江协板子上可能被板载外设占用，遇到问题优先换引脚。
- AFIO 时钟是外部中断的前提，必须开启。
- 中断标志位必须清除，否则中断连续触发，主程序卡死。
- 显示有符号数必须用 `OLED_ShowSignedNum()`，不能用 `OLED_ShowNum()`。
