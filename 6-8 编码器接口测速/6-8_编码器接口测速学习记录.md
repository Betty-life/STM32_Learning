# 6-8 编码器接口测速学习记录

## 一、实验功能

使用 TIM3（Timer 3，定时器 3）的编码器接口模式，读取旋转编码器的 A、B 相信号，通过硬件自动计数，测量旋转方向和速度。OLED（Organic Light-Emitting Diode，有机发光二极管）显示计数值。

## 二、硬件接线

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| 编码器 A 相 | PA6 | TIM3 通道 1（TI1，Timer Input 1，定时器输入 1） |
| 编码器 B 相 | PA7 | TIM3 通道 2（TI2，Timer Input 2，定时器输入 2） |
| OLED | PB8 | SCL（Serial Clock Line，串行时钟线） |
| OLED | PB9 | SDA（Serial Data Line，串行数据线） |

## 三、核心知识点

### 1. 编码器接口模式

编码器接口是定时器的一个特殊功能，用两个通道（A 相和 B 相）同时计数：

- **正转**：A 相超前 B 相，CNT（Counter，计数器）加一。
- **反转**：B 相超前 A 相，CNT 减一。
- **停止**：A/B 相不变，CNT 不变。

**硬件自动判断方向，不需要软件干预。**

### 2. 编码器模式和输入捕获的区别

| | 输入捕获（6-6/6-7） | 编码器接口（6-8） |
| --- | --- | --- |
| 引脚 | 一个通道 | 两个通道（A/B 相） |
| 计数方式 | 内部时钟 + 捕获边沿 | 外部 A/B 相脉冲 |
| 方向判断 | 软件判断 | 硬件自动判断 |
| 用途 | 测频率、脉宽 | 测转速、方向 |

### 3. 编码器接口的配置

编码器接口配置函数需要三个参数：编码器模式、A 相捕获极性、B 相捕获极性。

| 参数 | 值 | 含义 |
| --- | --- | --- |
| 编码器模式 | TI12 | 用 TI1 和 TI2 同时计数 |
| 捕获极性 | 上升沿 | 上升沿触发 |

编码器模式有三种：

- **TI1**：只用 TI1 计数。
- **TI2**：只用 TI2 计数。
- **TI12**：TI1 和 TI2 都用，精度最高。

### 4. 时基配置

| 参数 | 值 | 说明 |
| --- | --- | --- |
| PSC（Prescaler，预分频器） | 1 - 1 = 0 | 不分频，最高计数频率 |
| ARR（Auto-Reload Register，自动重装载寄存器） | 65536 - 1 | 最大值，让 CNT 在 -32768~32767 之间自由计数 |

**编码器模式下，PSC 通常设为 0，ARR 设为 65535。**

### 5. 滤波器配置

输入捕获结构体里的滤波器字段设为 `0xF`，即最强滤波。

**滤波器抗抖动**。编码器机械触点抖动严重，滤波器必须开。

## 四、重点

1. **编码器接口用两个通道**：A 相接 TIM3 通道 1（PA6），B 相接通道 2（PA7）。
2. **硬件自动判断方向**：正转 CNT 加一，反转 CNT 减一，不需要软件干预。
3. **编码器接口配置函数必须先调用**：它会自动配置两个通道的输入捕获。
4. **滤波器必须开**：编码器机械触点抖动严重，`0xF` 最强滤波。
5. **PSC = 0，ARR = 65535**：让 CNT 在最大范围自由计数。
6. **读取函数建议清零**：返回增量值，方便主循环累加。

## 五、错误记录

### 错误 1：编码器接口配置调用顺序反了
**现象**：编码器读数异常或不变。
**原因**：先配置了输入捕获，再调用编码器接口配置，配置被覆盖。
**解决**：先调用编码器接口配置函数，再用输入捕获初始化配置滤波器。

### 错误 2：读取函数没有清零
**现象**：主循环里读数一直累加，不会回到 0。
**原因**：读取函数返回的是累计值，不是增量值。
**解决**：读取后把计数器清零，让下次读取返回增量值。

### 错误 3：写了中断函数但没有初始化定时器
**现象**：编码器不动，速度一直是 0。
**原因**：写了定时器中断函数，但没有调用定时器初始化函数，定时器不工作，中断不触发。
**解决**：把定时器模块加入工程，调用定时器初始化函数。

### 错误 4：PA6/PA7 被板载外设占用
**现象**：编码器读数不变或乱跳。
**原因**：江协板子上 PA6/PA7 可能被其他外设占用。
**解决**：检查板子丝印或原理图，确认 PA6/PA7 空着，或者换到其他引脚。

## 六、经验总结

1. **编码器接口是硬件自动计数**，比外部中断方式稳定得多。
2. **A/B 相接两个通道**：A 相 PA6，B 相 PA7。
3. **编码器接口配置必须先调用**，再用输入捕获初始化配滤波器。
4. **滤波器开到 0xF**，抗机械抖动。
5. **PSC = 0，ARR = 65535**，让 CNT 在最大范围自由计数。
6. **读取函数建议清零**，返回增量值。
7. **中断方式需要初始化定时器**，不能只写中断函数。
