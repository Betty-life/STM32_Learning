# 5-1 对射式红外传感器计次学习记录

## 一、实验功能

红外传感器被遮挡时输出低电平，触发下降沿中断，计数加一，OLED 显示计数值。

## 二、硬件接线

| 外设 | 引脚 |
| --- | --- |
| 红外传感器（DO 输出） | PB14 |
| OLED（SCL） | PB8 |
| OLED（SDA） | PB9 |

## 三、代码结构

### CountSensor.c

```c
void CountSensor_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);

    GPIO_InitTypeDef GPIO_InitStruct;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_14;
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStruct);

    GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource14);

    EXTI_InitTypeDef EXTI_InitStruct;
    EXTI_InitStruct.EXTI_Line = EXTI_Line14;
    EXTI_InitStruct.EXTI_LineCmd = ENABLE;
    EXTI_InitStruct.EXTI_Mode = EXTI_Mode_Interrupt;
    EXTI_InitStruct.EXTI_Trigger = EXTI_Trigger_Falling;
    EXTI_Init(&EXTI_InitStruct);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);

    NVIC_InitTypeDef NVIC_InitStruct;
    NVIC_InitStruct.NVIC_IRQChannel = EXTI15_10_IRQn;
    NVIC_InitStruct.NVIC_IRQChannelCmd = ENABLE;
    NVIC_InitStruct.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStruct.NVIC_IRQChannelSubPriority = 1;
    NVIC_Init(&NVIC_InitStruct);
}
```

### 中断服务函数

```c
void EXTI15_10_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line14) == SET)
    {
        if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_14) == 0)
        {
            CountSensor_Count++;
        }
        EXTI_ClearITPendingBit(EXTI_Line14);
    }
}
```

> 注：`CountSensor_Count` 变量需在 CountSensor.c 中定义（如 `uint16_t CountSensor_Count;`），本记录未给出声明。

## 四、踩坑记录

### 错误 1：AFIO 时钟没开

**原因**：`GPIO_EXTILineConfig()` 依赖 AFIO 时钟，不开时钟映射无效。
**正确**：`RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);`

### 错误 2：中断函数名写错

PB14 对应 `EXTI15_10_IRQHandler`，不是 `EXTI14_IRQHandler`。PB10~PB15 共用同一个中断通道。

### 错误 3：标志位没清除

`EXTI_ClearITPendingBit(EXTI_Line14)` 必须调用，否则中断连续触发，主程序卡死。

### 错误 4：中断里调用 OLED 显示

中断里不要做耗时操作，否则屏幕乱码。中断里只做计数，显示放到主循环。

## 五、经验总结

- 引脚号、EXTI 线号、NVIC 通道号、中断函数名，四者必须完全匹配。
- AFIO 时钟是外部中断的前提。
- 中断里只做计数，显示放到主循环。
- 中断标志位必须清除，否则中断连续触发。
