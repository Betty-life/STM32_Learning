# 项目长期记忆 — STM32Project_my

## 项目性质
江协科技 STM32F103（标准外设库 SPL）教程跟练工程集，每个小节一个独立 Keil 工程目录，命名格式 `X-Y 实验名`。

## 项目约定
- **学习记录/笔记 md 文件放在对应的工程子文件夹内**，命名如 `5-1_对射式红外传感器计次学习记录.md`、`6-5 PWM驱动直流电机学习记录.md`、`7-1 AD单通道学习记录.md`。
- 记录结构固定为七节：一、实验功能 / 二、硬件接线 / 三、核心知识点 / 四、参数设置 / 五、重点 / 六、错误记录 / 七、经验总结。
- 代码目录约定：`User/`（main.c 等）、`Hardware/`（外设驱动 .c/.h）、`System/`、`Library/`、`Start/`。

## 高频踩坑点（跨章节通用）
1. 头文件声明与源文件定义的**参数类型必须一致**（如 `uint8_t` vs `int8_t`），否则编译器不报错但逻辑全错。
2. 外设初始化要**开对应时钟**（GPIOA 时钟、ADC1 时钟等）容易漏。
3. **引脚与通道/复用功能必须匹配**（PA0~PA3 → TIM2 通道1~4）。
4. 时钟超频限制：ADC 时钟 ≤ 14MHz。
