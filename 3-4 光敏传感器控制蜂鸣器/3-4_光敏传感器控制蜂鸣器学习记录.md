# 3-4 光敏传感器控制蜂鸣器学习记录

## 一、实验功能

光敏传感器检测环境光照强度，光照低于阈值时蜂鸣器鸣叫，高于阈值时停止。

## 二、硬件接线

| 外设 | 引脚 |
| --- | --- |
| 光敏传感器（DO 输出） | PB13 |
| 蜂鸣器 | PB12 |

## 三、代码结构

### LightSensor.c

```c
void LightSensor_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);

    GPIO_InitTypeDef GPIO_InitStruct;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_13;
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStruct);
}

uint8_t LightSensor_Get(void)
{
    return GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_13);  // ✅ 读输入寄存器
}
```

### Buzzer.c

```c
void Buzzer_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);

    GPIO_InitTypeDef GPIO_InitStruct;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_12;
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStruct);
}
```

### main.c

```c
int main(void)
{
    Buzzer_Init();
    LightSensor_Init();

    while (1)
    {
        if (LightSensor_Get() == 1)
        {
            Buzzer_ON();
        }
        else
        {
            Buzzer_OFF();
        }
    }
}
```

> 注：`Buzzer_ON()` / `Buzzer_OFF()` 在本记录中未给出实现，需在 Buzzer.c 中补充（置位 / 复位 PB12 即可）。

## 四、踩坑记录

### 错误 1：LightSensor_Get() 用了 GPIO_ReadOutputDataBit

错误代码：

```c
return GPIO_ReadOutputDataBit(GPIOB, GPIO_Pin_13);  // ❌ 读的是输出寄存器
```

**原因**：光敏传感器是输入设备，DO 引脚输出高低电平给 STM32。必须用 `GPIO_ReadInputDataBit()` 读输入寄存器。`GPIO_ReadOutputDataBit()` 读的是之前写进 ODR 的值，和外部电平无关。

正确代码：

```c
return GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_13);  // ✅ 读输入寄存器
```

### 优化建议

主循环里 `LightSensor_Get()` 调用了两次，建议只读一次存变量：

```c
uint8_t light = LightSensor_Get();
if (light == 1)
{
    Buzzer_ON();
}
else
{
    Buzzer_OFF();
}
```

## 五、经验总结

- 输入设备用 `GPIO_ReadInputDataBit()`，输出设备用 `GPIO_ReadOutputDataBit()`。
- 光敏传感器不需要消抖，它是电子元件，没有机械抖动。
- 光敏传感器在阈值附近可能频繁跳变，可加软件迟滞避免蜂鸣器"哒哒哒"响。
- 主循环里尽量只读一次传感器，避免临界点两次读取结果不一致。
