# 7-1 AD单通道学习记录

## 一、实验功能

使用 ADC1 的通道 0（PA0）采集模拟电压，OLED 显示 AD 转换值和换算后的电压值。旋转电位器，观察数值变化。

## 三、核心知识点

### 1. ADC 是什么

ADC（Analog-to-Digital Converter，模数转换器）把**模拟电压**转换成**数字**。

- STM32F103 的 ADC 是 **12 位**的，把 0~3.3V 分成 4096 份。
- 0V → 0，3.3V → 4095，1.65V → 约 2048。
- 计算公式：`电压 = AD值 / 4095 × 3.3V`

### 2. ADC 时钟

ADC 时钟不能超过 **14MHz**，72MHz 太快，必须分频。

- `RCC_ADCCLKConfig(RCC_PCLK2_Div6)`：72MHz ÷ 6 = **12MHz** ✅
- `RCC_ADCCLKConfig(RCC_PCLK2_Div4)`：72MHz ÷ 4 = 18MHz ❌ 超过 14MHz

### 3. 采样时间

ADC 转换分两个阶段：

- **采样阶段**：采样电容充电，采集引脚电压。**时间由你配置**，可选 1.5~239.5 周期。
- **转换阶段**：把采样电压转成数字。**固定 12.5 周期**。

**总转换时间 = 采样时间 + 12.5 周期。**

| 采样时间 | 总周期 | 转换时间（ADCCLK=12MHz） |
|---|---|---|
| 1.5 周期 | 14 | ≈ 1.17us |
| 55.5 周期 | 68 | ≈ 5.67us |
| 239.5 周期 | 252 | ≈ 21us |

**采样时间越长，精度越高，但转换越慢。**

### 4. ADC 初始化步骤

1. **开时钟**：`RCC_APB2PeriphClockCmd(RCC_APB2Periph_ADC1, ENABLE)`
2. **设 ADC 时钟**：`RCC_ADCCLKConfig(RCC_PCLK2_Div6)`
3. **配 GPIO**：`GPIO_Mode_AIN`（模拟输入）
4. **配规则组通道**：`ADC_RegularChannelConfig`
5. **初始化 ADC**：`ADC_Init`
6. **使能 ADC**：`ADC_Cmd(ADC1, ENABLE)`
7. **校准**：`ADC_ResetCalibration` + `ADC_StartCalibration`

### 5. 等待逻辑

| 函数 | 返回值含义 | 循环条件 | 跳出条件 |
|---|---|---|---|
| `ADC_GetResetCalibrationStatus` | SET = 正在复位 | `== SET` | 变成 RESET |
| `ADC_GetCalibrationStatus` | SET = 正在校准 | `== SET` | 变成 RESET |
| `ADC_GetFlagStatus(ADC_FLAG_EOC)` | SET = 转换完成 | `== RESET` | 变成 SET |

**关键**：看函数返回值含义。SET 表示“正在忙”就等 RESET；SET 表示“已完成”就等 SET。

### 6. 触发方式

- **软件触发**：`ADC_SoftwareStartConvCmd(ADC1, ENABLE)`，代码主动触发。
- **外部触发**：定时器 TRGO 等硬件触发，用于自动采样。

本实验用软件触发。

## 五、重点

1. **ADC 时钟不能超过 14MHz**，必须用 `RCC_ADCCLKConfig` 分频。
2. **GPIO 必须配成 `GPIO_Mode_AIN`**（模拟输入），关掉施密特触发器。
3. **规则组通道必须配置**，告诉 ADC 转换哪个通道、采样时间多少。
4. **`ADC_Cmd(ADC1, ENABLE)` 是 ADC 总开关**，不调用 ADC 不工作。
5. **校准是固定流程**，每次上电必须校准一次。
6. **采样时间越长精度越高**，但转换越慢。
7. **12 位 ADC 最大值是 4095**，不是 4059，计算公式要写对。

## 六、错误记录

### 错误 1：缺少 `RCC_ADCCLKConfig()`

**现象**：ADC 读数不准或异常。

**原因**：ADC 时钟不能超过 14MHz，72MHz 直接给 ADC 会超频。

**解决**：加上 `RCC_ADCCLKConfig(RCC_PCLK2_Div6)`，ADCCLK = 12MHz。

### 错误 2：缺少 `ADC_RegularChannelConfig()`

**现象**：ADC 不转换或读数异常。

**原因**：规则组通道必须配置，告诉 ADC 转换哪个通道。

**解决**：加上 `ADC_RegularChannelConfig(ADC1, ADC_Channel_0, 1, ADC_SampleTime_55Cycles5)`。

### 错误 3：缺少 `ADC_Cmd(ADC1, ENABLE)`

**现象**：ADC 不工作。

**原因**：`ADC_Cmd` 是 ADC 总开关，不调用 ADC 不工作。

**解决**：加上 `ADC_Cmd(ADC1, ENABLE)`。

### 错误 4：`main.c` 里分母写成 4059

**现象**：电压计算偏大。

**原因**：12 位 ADC 最大值是 4095，不是 4059。

**解决**：改成 `Voltage = (float)ADValue / 4095 * 3.3;`。

### 错误 5：`AD.h` 缺少分号

**现象**：编译报错。

**原因**：函数声明末尾没有分号。

**解决**：加上 `uint16_t AD_GetValue(void);`。

### 错误 6：多余的 `ADC_DMACmd`

**现象**：无影响，但代码冗余。

**原因**：没有用 DMA，不需要使能 DMA 请求。

**解决**：删掉 `ADC_DMACmd(ADC1, ENABLE);`。

---

## 七、经验总结

1. **ADC 时钟不能超过 14MHz**，必须用 `RCC_ADCCLKConfig` 分频。
2. **GPIO 配成 `GPIO_Mode_AIN`**，关掉施密特触发器。
3. **规则组通道必须配置**，采样时间根据信号源阻抗选择。
4. **`ADC_Cmd` 是总开关**，不调用 ADC 不工作。
5. **校准是固定流程**，每次上电必须校准。
6. **等待逻辑看返回值含义**：SET 表示“正在忙”就等 RESET，SET 表示“已完成”就等 SET。
7. **12 位 ADC 最大值是 4095**，电压 = AD值 / 4095 × 3.3V。
8. **ADC 读数会抖动**，可以用多次采样取平均或一阶低通滤波减小抖动。
9. **施密特滤波适合阈值判断**（白天/黑夜、低电量），平均滤波适合连续变化信号（电位器、温度）。
