# 6-4 PWM驱动舵机学习记录

## 一、实验功能

使用 TIM2（Timer 2，定时器 2）通道 2（PA1）输出 50Hz PWM（Pulse Width Modulation，脉冲宽度调制）波，通过调节 CCR 值改变脉宽（0.5ms~2.5ms），控制舵机转动角度（0°~180°）。按键按下时角度增加 30°，超过 180° 归零，OLED（Organic Light-Emitting Diode，有机发光二极管）显示当前角度和键码。

## 二、硬件接线

| 外设 | 引脚 |
|---|---|
| 舵机信号线（橙/黄/白） | PA1 |
| 舵机 VCC（电源正极，红线） | 独立 5V 电源正极 |
| 舵机 GND（Ground，地；黑/棕线） | 独立 5V 电源负极 + STM32 GND（共地） |
| OLED SCL（Serial Clock Line，串行时钟线） | PB8 |
| OLED SDA（Serial Data Line，串行数据线） | PB9 |
| 按键 | PB11（不能用 PB1） |

## 三、核心知识点

### 1. 舵机控制原理

舵机内部有一个控制芯片，它通过**检测 PWM 信号的脉宽**来决定转动角度：

| 脉宽 | 舵机角度 |
|---|---|
| 0.5ms | 0° |
| 1.0ms | 45° |
| 1.5ms | 90°（中位） |
| 2.0ms | 135° |
| 2.5ms | 180° |

**PWM 周期必须是 20ms（50Hz）。**

### 2. CCR 与脉宽的换算

（CCR，Capture/Compare Register，捕获/比较寄存器；ARR，Auto-Reload Register，自动重装载寄存器）

\[
CCR = \frac{脉宽}{20ms} \times (ARR+1)
\]

本实验配置：PSC（Prescaler，预分频器）= 72 - 1 = 71，ARR = 20000 - 1 = 19999。

\[
CCR = \frac{脉宽}{20ms} \times 20000
\]

| 脉宽 | CCR | 角度 |
|---|---|---|
| 0.5ms | 500 | 0° |
| 1.0ms | 1000 | 45° |
| 1.5ms | 1500 | 90° |
| 2.0ms | 2000 | 135° |
| 2.5ms | 2500 | 180° |

### 3. 角度到 CCR 的映射公式

\[
CCR = \frac{Angle}{180} \times 2000 + 500
\]

- Angle = 0° → CCR = 500
- Angle = 90° → CCR = 1500
- Angle = 180° → CCR = 2500

### 4. 舵机供电要求

- **舵机必须独立供电**，不能直接用 STM32 的 3.3V 或 5V 引脚供电。
- 舵机工作电流较大（可能超过 500mA），用 STM32 引脚供电会导致电压跌落、复位甚至烧毁芯片。
- **舵机 VCC 接 5V 独立电源，舵机 GND 必须和 STM32 GND 共地。**

## 四、参数设置详解

### 1. PSC（预分频器）怎么设？

**PSC 决定计数器的计数频率**：CK_CNT = 72MHz / (PSC+1)。
**舵机要求 PWM 周期 = 20ms，即频率 = 50Hz。**

**设置思路**：
- 先定一个方便的计数频率。比如让 CK_CNT = 1MHz，即每 1us 数一个数。
- 72MHz / (PSC+1) = 1MHz → PSC+1 = 72 → **PSC = 71**。
- 这样计数器每 1us 数一个数，20ms 对应 20000 个数。

**为什么选 1MHz**：脉宽是 0.5ms~2.5ms，用 1us 为单位，CCR 值就是 500~2500，整数好算。

### 2. ARR（自动重装载值）怎么设？

**ARR 决定 PWM 周期**：周期 = (ARR+1) / CK_CNT。
**舵机要求周期 = 20ms**：
- (ARR+1) / 1MHz = 20ms → ARR+1 = 20000 → **ARR = 19999**。

**结论**：PSC = 71，ARR = 19999，PWM 频率 = 50Hz，周期 = 20ms。

### 3. CCR 怎么设？

**CCR 决定脉宽**：脉宽 = CCR / CK_CNT。
**舵机脉宽范围 0.5ms~2.5ms**：
- 0.5ms → CCR = 0.5ms × 1MHz = **500**
- 1.5ms → CCR = 1.5ms × 1MHz = **1500**
- 2.5ms → CCR = 2.5ms × 1MHz = **2500**

### 4. 不同外设的参数怎么设？

| 外设 | PWM 频率 | PSC | ARR | CCR 范围 |
|---|---|---|---|---|
| **舵机** | 50Hz | 71 | 19999 | 500~2500 |
| **LED 呼吸灯** | 1kHz | 719 | 99 | 0~99 |
| **直流电机** | 10kHz~20kHz | 71 | 99 | 0~99 |
| **无源蜂鸣器** | 1kHz~5kHz | 719 | 99 | 50（固定占空比） |

**设置思路**：
1. **先确定 PWM 频率**（由外设决定）。
2. **选一个方便的 CK_CNT**（比如 1MHz）。
3. **算 PSC**：PSC = 72MHz / CK_CNT - 1。
4. **算 ARR**：ARR = CK_CNT / PWM频率 - 1。
5. **算 CCR**：CCR = 脉宽 × CK_CNT。

### 5. 不同场景下 PWM 模式怎么选？

| 场景 | PWM 模式 | 极性 |
|---|---|---|
| LED 高电平点亮 | PWM1 | High |
| LED 低电平点亮 | PWM1 | Low |
| 舵机 | PWM1 | High |
| 电机调速 | PWM1 | High |
| 无源蜂鸣器 | PWM1 | High |

**大多数场景用 PWM 模式 1 + 高电平有效。**

### 6. 什么时候用预装载？

| 场景 | 是否使能预装载 |
|---|---|
| 动态修改 CCR（呼吸灯、舵机扫描） | ✅ 使能 |
| 固定占空比 | 无所谓 |
| 输入捕获 | 不涉及 |

**`TIM_OC2PreloadConfig(TIM2, TIM_OCPreload_Enable)`（OC，Output Compare，输出比较）放在 `TIM_OC2Init()` 之后。**

## 五、重点

1. **PWM 频率必须是 50Hz**：PSC 和 ARR 的配置必须保证周期为 20ms。
2. **通道 2 对应 PA1**：`TIM_OC2Init` 对应通道 2，引脚是 PA1，不能接 PA0。
3. **共地是信号通信的前提**：舵机 GND 和 STM32 GND 必须连通。
4. **舵机独立供电**：不要用 STM32 引脚给舵机供电。
5. **`TIM_OC2PreloadConfig` 使能预装载**：让 CCR 修改在周期边界生效，舵机转动更平滑。
6. **先给中位 1500 测试**：确认舵机能转到中间位置，再尝试其他角度。

## 六、错误记录

### 错误 1：信号线插到 PA0，代码用的是 PA1

**现象**：舵机不转。
**原因**：代码配置的是 TIM2 通道 2，对应引脚是 PA1。信号线插在 PA0 上，PA0 对应通道 1，代码没有初始化通道 1，所以 PA0 没有 PWM 输出。
**解决**：把信号线插到 PA1，或者改代码用通道 1（PA0）。

### 错误 2：舵机和 STM32 没有共地

**现象**：舵机不转，或者堵转发热。
**原因**：舵机 GND 和 STM32 GND 没有连通，PWM 信号没有参考点，舵机无法正确解析信号。
**解决**：用杜邦线把舵机 GND 和 STM32 GND 直接连在一起，用万用表通断档确认蜂鸣响。

### 错误 3：舵机供电不足

**现象**：舵机不转，或者堵转发热。
**原因**：舵机供电电压只有 4V（标准是 5V），力矩不足，电机堵转。
**解决**：换一个稳定的 5V 电源，确保带载后电压不低于 4.8V。

### 错误 4：舵机堵转发烫

**现象**：舵机发烫，有"嗡嗡"声。
**原因**：CCR 值超出舵机机械行程，电机使劲往极限位置顶，电流过大。
**解决**：立刻断电，把 CCR 调回 1500（中位），确认舵机能正常转动后再尝试其他角度。如果持续发烫，舵机可能已经损坏。

### 错误 5：按键用 PB1 不生效

**现象**：按键按下没反应，用杜邦线直接触碰 PB1 和 GND 才能触发。
**原因**：江协板子上 PB1 被板载外设（LED 或按键）占用，板载上拉电阻把 PB1 拉在高电平，外部按键按下时拉不低。
**解决**：按键换到 PB11（或板子上其他确认空着的引脚）。

### 错误 6：`Servo.c` 里 `#include "PEM.h"` 拼写错误

**现象**：编译报错 `cannot open source input file "PEM.h"`。
**原因**：手误把 `PWM.h` 打成了 `PEM.h`。
**解决**：改成 `#include "PWM.h"`。

### 错误 7：新建 `Servo.c` 没加入 Keil 工程

**现象**：弹窗提示 `Browse information of one or more files is not available`。
**原因**：`Servo.c` 没被加入工程，或者编译时没勾选 Browse Information。
**解决**：右键工程文件夹 → Add Existing Files to Group，把 `Servo.c` 加进去；魔术棒 → Output → 勾选 Browse Information；重新编译。

## 七、经验总结

1. **舵机 PWM 频率必须是 50Hz**，周期 20ms，PSC 和 ARR 要配合好。
2. **通道号对应引脚**：通道 1 → PA0，通道 2 → PA1，通道 3 → PA2，通道 4 → PA3。
3. **舵机必须独立 5V 供电**，且和 STM32 共地。
4. **先给中位 1500 测试**，确认舵机能转到中间，再尝试其他角度。
5. **CCR 超出舵机行程会导致堵转发烫**，立刻断电，调回中位。
6. **PB1 在江协板子上被板载外设占用**，按键和编码器都不要用 PB1，换 PB11 或 PB5。
7. **万用表测不出占空比**，只能测平均电压估算。要精确测频率和脉宽，需要逻辑分析仪或示波器。
8. **舵机三根线**：红线 VCC（电源正极），黑/棕线 GND（地，共地），橙/黄/白线信号（PA1）。
9. **参数设置思路**：先定 PWM 频率 → 选 CK_CNT → 算 PSC → 算 ARR → 算 CCR。
10. **不同外设的 PWM 频率不同**：舵机 50Hz，LED 1kHz，电机 10kHz~20kHz。
