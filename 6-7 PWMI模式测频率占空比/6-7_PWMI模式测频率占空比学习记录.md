# 6-7 PWMI模式测频率占空比学习记录

## 一、实验功能

使用 TIM2（Timer 2，定时器 2）通道 1（PA0）输出 1kHz 的 PWM（Pulse Width Modulation，脉冲宽度调制）波，用杜邦线连接到 TIM3（Timer 3，定时器 3）通道 1（PA6），通过 PWMI（PWM Input，PWM 输入）模式同时测量 PWM 信号的频率和占空比，OLED（Organic Light-Emitting Diode，有机发光二极管）显示测量结果。

## 二、硬件接线

| 外设 | 引脚 | 说明 |
| --- | --- | --- |
| PWM 输出（TIM2 通道 1） | PA0 | 1kHz PWM 信号源 |
| 输入捕获（TIM3 通道 1） | PA6 | 用杜邦线与 PA0 相连，接收 PWM 信号 |
| OLED | PB8 | SCL（Serial Clock Line，串行时钟线） |
| OLED | PB9 | SDA（Serial Data Line，串行数据线） |

**注意**：PA0 和 PA6 必须用杜邦线连在一起。

## 三、核心知识点

### 1. PWMI 模式原理

PWMI（PWM Input，PWM 输入）模式是输入捕获的一种应用，**用两个通道同时测量周期和高电平时间**：

- **通道 1**：上升沿捕获，记录整个周期（CCR1，Capture/Compare Register 1，捕获/比较寄存器 1）。
- **通道 2**：下降沿捕获，记录高电平时间（CCR2）。

\[
频率 = \frac{计数频率}{CCR1}
\]

\[
占空比 = \frac{CCR2}{CCR1} \times 100\%
\]

### 2. PWMI 配置函数的作用

PWMI 配置函数会自动配置两个通道：

- **通道 1**：直通模式（TI1 → IC1），上升沿捕获。
- **通道 2**：交叉模式（TI1 → IC2），下降沿捕获。

**只需要配置通道 1 的结构体，配置函数会自动配置通道 2。**

### 3. 输入捕获的直通和交叉

| 模式 | 信号路径 | 什么时候用 |
| --- | --- | --- |
| 直通（DirectTI） | TI1 → IC1，TI2 → IC2 | 信号接在对应通道引脚上 |
| 交叉（IndirectTI） | TI1 → IC2，TI2 → IC1 | 信号接在另一个通道引脚上 |

**PWMI 模式下，通道 1 用直通，通道 2 自动用交叉，让 TI1 的信号同时送到 IC1 和 IC2。**

### 4. 从模式（Slave Mode）的作用

**没有从模式**：CCR 累加，测的是总时间，不是周期。

**有从模式**：每次捕获后 CNT（Counter，计数器）自动清零，CCR 等于一个周期。

配置上需要两处配合：
- **选择触发源**：选择 TI1FP1（通道 1 滤波后的输入信号）作为触发源，让捕获事件作为触发。
- **配置从模式复位**：配置从模式为复位（Reset），触发时把 CNT 清零。

### 5. 输入捕获配置参数

| 字段 | 作用 | 常用值 |
| --- | --- | --- |
| 通道（TIM_Channel） | 用哪个通道 | 通道 1（TIM_Channel_1） |
| 捕获极性（TIM_ICPolarity） | 触发边沿 | 上升沿（TIM_ICPolarity_Rising） |
| 输入选择（TIM_ICSelection） | 输入选择 | 直连输入（TIM_ICSelection_DirectTI） |
| 捕获预分频（TIM_ICPrescaler） | 捕获预分频 | 不分频（TIM_ICPSC_DIV1） |
| 滤波器（TIM_ICFilter） | 滤波器 | 0x3 ~ 0xF |

## 四、参数计算

### PWM 配置（TIM2 通道 1）

- PSC（Prescaler，预分频器）= 720 - 1 = 719
- ARR（Auto-Reload Register，自动重装载寄存器）= 100 - 1 = 99
- CCR = 50
- PWM 频率 = 72MHz / 720 / 100 = **1kHz**
- 占空比 = 50 / 100 = **50%**

\[
PWM频率 = \frac{72,000,000}{720 \times 100} = 1,000Hz = 1kHz
\]

\[
占空比 = \frac{50}{100} \times 100\% = 50\%
\]

### 输入捕获配置（TIM3 通道 1）

- PSC = 72 - 1 = 71
- 计数频率 = 72MHz / 72 = **1MHz**
- 一个周期计数 = 1MHz / 1kHz = **1000**
- 理论 CCR1 = 1000
- 理论频率 = 1000000 / 1000 = **1000Hz**
- 理论占空比 = 500 / 1000 = **50%**

\[
计数频率 = \frac{72,000,000}{72} = 1,000,000Hz
\]

\[
理论频率 = \frac{1,000,000}{1,000} = 1,000Hz
\]

\[
理论占空比 = \frac{500}{1,000} \times 100\% = 50\%
\]

### 实测结果

| 参数 | 理论值 | 实测值 | 误差 |
| --- | --- | --- | --- |
| 频率 | 1000Hz | 1001Hz | 0.1% |
| 占空比 | 50% | 49% | 1% |

**误差来源**：PWM 信号和输入捕获计数时钟独立，边沿检测有微小时间差。**误差在 1% 以内，实验合格。**

## 五、重点

1. **PWMI 模式用两个通道**：通道 1 测周期，通道 2 测高电平时间。
2. **配置函数自动配置通道 2**：只配置通道 1，通道 2 自动配置为交叉模式。
3. **从模式必须配置**：选择 TI1FP1 作为触发源 + 配置从模式复位，让每次捕获后 CNT 自动清零。
4. **结构体初始化函数要放在赋值之前**：否则前面的赋值会被默认值覆盖。
5. **PA0 和 PA6 必须连在一起**：PWM 输出直接给输入捕获测频。
6. **频率 = 计数频率 / CCR1，占空比 = CCR2 / CCR1 × 100%**。
7. **CCR1 和 CCR2 不能为 0**：做除法时要加保护。

## 六、错误记录

### 错误 1：两行显示写到了同一个位置
**现象**：只能看到频率，看不到占空比。
**原因**：两行都显示在第 1 行第 6 列，后面的覆盖前面的。
**解决**：占空比改到第 2 行显示。

### 错误 2：缺少结构体初始化
**现象**：结构体残留随机值，配置异常。
**原因**：没有先调用结构体初始化函数填默认值。
**解决**：在赋值之前先调用结构体初始化函数。

### 错误 3：缺少从模式配置，计数器累加
**现象**：显示 113Hz，数据跳动。
**原因**：没有配置从模式，捕获后计数器不清零，CCR 累加。
**解决**：加上从模式配置：选择 TI1FP1 作为触发源，配置从模式复位。

### 错误 4：PWM 比较值超过自动重装载值
**现象**：PWM 占空比 100%，没有上升沿。
**原因**：自动重装载值只有 99，比较值却设成 719，超过自动重装载值。
**解决**：把比较值调回 50。

### 错误 5：占空比计算可能溢出或除零
**现象**：占空比显示异常。
**原因**：高电平时间乘以 100 可能溢出，或者 CCR1 为 0。
**解决**：先乘后除，并加除零保护。

## 七、经验总结

1. **PWMI 模式是输入捕获的高级应用**，用两个通道同时测周期和高电平时间。
2. **配置函数自动配置两个通道**，通道 1 直通，通道 2 交叉。
3. **从模式是输入捕获测频率的标配**，让每次捕获后 CNT 自动清零。
4. **结构体初始化必须放在赋值之前**。
5. **PA0 和 PA6 必须连在一起**，PWM 输出直接给输入捕获测频。
6. **频率 = 计数频率 / CCR1，占空比 = CCR2 / CCR1 × 100%**。
7. **测量误差在 1% 以内是正常的**，因为 PWM 信号和输入捕获计数时钟独立。
8. **直通和交叉的选择**：信号接在哪个引脚，就用哪个通道的直通；PWMI 模式下通道 2 自动用交叉。
