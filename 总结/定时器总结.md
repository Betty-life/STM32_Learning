# 定时器总结

## 一、定时器的三种时钟源

| 时钟源 | 触发方式 | 典型用途 |
| --- | --- | --- |
| 内部时钟 | 72MHz 自动计数 | 定时中断、PWM（Pulse Width Modulation，脉冲宽度调制）输出 |
| 外部时钟模式 1 | 外部引脚脉冲触发 | 外部脉冲计数 |
| 外部时钟模式 2 | 外部引脚脉冲触发 | 外部脉冲计数 |
| 编码器接口 | A/B 相脉冲触发 | 读旋转编码器 |

**判断方法**：看代码里调用了哪个配置函数（内部时钟选择、外部时钟模式配置、编码器接口配置）。

## 二、定时器的核心参数

| 参数 | 作用 | 公式 |
| --- | --- | --- |
| PSC（Prescaler，预分频器） | 预分频器，决定计数频率 | 计数频率 = 72MHz / (PSC+1) |
| ARR（Auto-Reload Register，自动重装载寄存器） | 自动重装载值，决定溢出周期 | 中断周期 = (PSC+1) × (ARR+1) / 72MHz |
| CCR（Capture/Compare Register，捕获/比较寄存器） | 捕获/比较寄存器 | PWM 占空比 = CCR / (ARR+1) |

\[
计数频率 = \frac{72MHz}{PSC+1}
\]

\[
中断周期 = \frac{(PSC+1) \times (ARR+1)}{72MHz}
\]

\[
PWM占空比 = \frac{CCR}{ARR+1}
\]

**PSC 决定"每格多快"，ARR 决定"数多少格归零"，CCR 决定"高电平多长"。**

## 三、定时器的四种功能

### 1. 定时中断

- 时钟源：内部时钟
- 配置：内部时钟选择 + 更新中断使能（TIM_ITConfig）+ 中断控制器（NVIC，Nested Vectored Interrupt Controller，嵌套向量中断控制器）配置
- 用途：按键扫描、编码器测速、传感器采集

### 2. 输出比较（PWM）

- 时钟源：内部时钟
- 配置：输出比较初始化（TIM_OCInit）+ 预装载使能（TIM_OCPreloadConfig）
- 用途：呼吸灯、舵机、电机调速

### 3. 输入捕获

- 时钟源：内部时钟 + 输入捕获
- 配置：输入捕获初始化（TIM_ICInit）+ 触发源选择（TIM_SelectInputTrigger）+ 从模式复位（TIM_SelectSlaveMode）
- 用途：测频率、测脉宽、测占空比

### 4. 编码器接口

- 时钟源：编码器接口
- 配置：编码器接口配置（TIM_EncoderInterfaceConfig）+ 输入捕获初始化（TIM_ICInit）
- 用途：读旋转编码器、测转速和方向

## 五、通道和引脚对应关系

| 通道 | TIM2（定时器 2） | TIM3（定时器 3） | TIM4（定时器 4） |
| --- | --- | --- | --- |
| 通道 1 | PA0 | PA6 | PB6 |
| 通道 2 | PA1 | PA7 | PB7 |
| 通道 3 | PA2 | PB0 | PB8 |
| 通道 4 | PA3 | PB1 | PB9 |

**注意**：引脚和通道必须匹配，否则 PWM 或输入捕获不工作。

## 六、常见错误

1. **时钟、初始化、操作端口不一致**：开 GPIOA（General Purpose Input/Output，通用输入/输出 A 端口）时钟，初始化 GPIOA，操作 GPIOA。三者必须统一。
2. **引脚和通道不匹配**：PA0 → 通道 1，PA1 → 通道 2，PA2 → 通道 3，PA3 → 通道 4。
3. **忘记定时器使能**：定时器使能函数（TIM_Cmd）是定时器总开关，不调用 CNT（Counter，计数器）不计数。
4. **忘记清除中断标志位**：中断函数里必须调用中断标志清除函数（TIM_ClearITPendingBit），否则中断连续触发。
5. **中断函数名写错**：TIM2 → `TIM2_IRQHandler`，TIM3 → `TIM3_IRQHandler`。
6. **PWM 输出引脚配成普通推挽输出**：PWM 输出必须配复用推挽输出（GPIO_Mode_AF_PP，Alternate Function Push-Pull）。
7. **输入捕获缺少从模式配置**：选择 TI1FP1 作为触发源 + 配置从模式复位，让捕获后计数器自动清零。
8. **编码器接口调用顺序反了**：先编码器接口配置（TIM_EncoderInterfaceConfig），再输入捕获初始化（TIM_ICInit）配滤波器。

## 七、经验总结

1. **定时器的核心是 PSC 和 ARR**：PSC 决定计数频率，ARR 决定溢出周期。
2. **时钟源决定计数方式**：内部时钟自动计数，外部时钟靠脉冲，编码器接口靠 A/B 相。
3. **输出比较和输入捕获是定时器的两个方向**：一个往外输出，一个往里读取。
4. **中断里只做计数，显示放到主循环**。
5. **引脚、通道、中断函数名，三者必须匹配**。
6. **遇到问题不超 2 小时**：卡住就跳过，继续往下学，回头再看。
7. **定时器是 STM32 最核心的外设**：PWM、输入捕获、编码器接口都靠它，学扎实了后面学 ADC、DMA 会轻松很多。
