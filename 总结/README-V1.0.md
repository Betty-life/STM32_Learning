## 踩坑总结
### 硬件相关
- **PB1 被板载外设占用**：江协板子上 PB1 同时接了 LED 或按键，外部信号拉不低它。按键和编码器都不要用 PB1，换 PB11 或 PB5。
- **舵机必须独立 5V 供电**：用 STM32 引脚供电会导致电压跌落、复位甚至烧毁芯片。舵机 GND 必须和 STM32 GND 共地。
- **共地是信号通信的前提**：按键、编码器、舵机、传感器，都要和 STM32 共地。
- **杜邦线内部断线很常见**：遇到"玄学问题"，先换一根杜邦线。
### 代码相关
- **GPIO 模式不能写错**：输出设备用 `GPIO_Mode_Out_PP`，PWM 输出用 `GPIO_Mode_AF_PP`，输入设备用 `GPIO_Mode_IPU` 或 `GPIO_Mode_IPD`。
- **时钟、初始化、操作三者必须统一端口**：开 GPIOA 时钟就初始化 GPIOA、操作 GPIOA。
- **中断函数名必须和启动文件一致**：PB0 → `EXTI0_IRQHandler`，PB5 → `EXTI9_5_IRQHandler`，PB12 → `EXTI15_10_IRQHandler`。
- **中断里只做计数，显示放到主循环**：中断里调用 OLED 显示会导致屏幕乱码。
- **函数声明了返回值就必须 `return`**：否则主调函数读到随机值。
- **显示有符号数必须用 `OLED_ShowSignedNum()`**：不能用 `OLED_ShowNum()`，否则负数显示成 67292。
- **PWM 输出必须使能预装载**：`TIM_OCxPreloadConfig()`，让 CCR 修改在周期边界生效，波形更平滑。
### 调试方法
- **用模拟代码隔离问题**：在 `while(1)` 里手动操作 GPIO 产生边沿，绕过硬件，验证中断逻辑。
- **用轮询验证引脚信号**：用 OLED 显示引脚电平，判断信号是否到达 STM32。
- **用万用表测电压和通断**：排查供电、共地、杜邦线问题。
- **遇到问题不超 2 小时**：卡住就跳过，继续往下学，回头再看。
