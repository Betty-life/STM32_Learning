# 6-2 定时器外部时钟学习记录

## 一、实验功能

使用 TIM2 的 ETR（外部触发输入）引脚 PA0 作为外部时钟源，每来一个脉冲，计数器 CNT 加一，CNT 数到 ARR 值时溢出，触发中断，`Num` 自增。OLED 显示溢出次数 `Num` 和当前计数值 `CNT`。

---

## 二、硬件接线

| 外设 | 引脚 |
|---|---|
| 外部脉冲信号源 | PA0 |
| OLED SCL | PB8 |
| OLED SDA | PB9 |

---

## 三、代码结构

### Timer.c

```c
#include "stm32f10x.h"

extern uint16_t Num;

void Timer_Init(void)
{
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    TIM_ETRClockMode2Config(TIM2, TIM_ExtTRGPSC_OFF, TIM_ExtTRGPolarity_NonInverted, 0x0A);

    TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
    TIM_TimeBaseInitStructure.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseInitStructure.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInitStructure.TIM_Period = 10 - 1;
    TIM_TimeBaseInitStructure.TIM_Prescaler = 1 - 1;
    TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

    TIM_ClearFlag(TIM2, TIM_FLAG_Update);
    TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);

    NVIC_InitTypeDef NVIC_InitStructure;
    NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelCmd = ENABLE;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority = 1;
    NVIC_Init(&NVIC_InitStructure);

    TIM_Cmd(TIM2, ENABLE);
}

uint16_t Timer_Count(void)
{
    return TIM_GetCounter(TIM2);
}

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) == SET)
    {
        Num++;
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
    }
}
```

### main.c

```c
#include "stm32f10x.h"
#include "Delay.h"
#include "OLED.h"
#include "Timer.h"

uint16_t Num;

int main(void)
{
    OLED_Init();
    Timer_Init();

    OLED_ShowString(1, 1, "Num:");
    OLED_ShowString(2, 1, "CNT:");

    while (1)
    {
        OLED_ShowNum(1, 5, Num, 5);
        OLED_ShowNum(2, 5, Timer_Count(), 5);
    }
}
```

## 四、关键函数详解

### 1. `TIM_ETRClockMode2Config(TIM2, TIM_ExtTRGPSC_OFF, TIM_ExtTRGPolarity_NonInverted, 0x0A);`

**作用**：配置定时器的外部触发输入（ETR）为时钟源。
**参数**：
- 第 2 个参数：外部触发预分频器，`TIM_ExtTRGPSC_OFF` 表示不分频。
- 第 3 个参数：外部触发极性，`TIM_ExtTRGPolarity_NonInverted` 表示上升沿有效。
- 第 4 个参数：外部触发滤波器，值越大滤波越强。`0x0A` 是中等滤波，信号干净时可以填 `0x00`。

**什么时候用**：需要外部脉冲驱动计数器时用，比如按键计数、编码器计数。

---

### 2. `TIM_ClearFlag(TIM2, TIM_FLAG_Update);`

**作用**：清除更新标志位（SR 寄存器里的 UIF 位）。
**什么时候用**：在 `TIM_TimeBaseInit()` 之后、`TIM_ITConfig()` 之前调用。
**注意**：这里用 `TIM_FLAG_Update`（标志位），而 6-1 里用 `TIM_IT_Update`（中断标志）。两者都可以清除标志位，但：
- `TIM_FLAG_Update` 用于 `TIM_GetFlagStatus` 和 `TIM_ClearFlag`。
- `TIM_IT_Update` 用于 `TIM_GetITStatus` 和 `TIM_ClearITPendingBit`。

---

### 3. `TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);`

**作用**：使能定时器的更新中断（UIE 位）。
**什么时候用**：在 `TIM_TimeBaseInit()` 之后调用。
**不调用会怎样**：定时器溢出时不会触发中断，`TIM2_IRQHandler` 永远不会执行。

---

### 4. `TIM_Cmd(TIM2, ENABLE);`

**作用**：启动定时器（使能计数器 CNT 开始计数）。
**什么时候用**：所有配置完成后，最后一步调用。
**不调用会怎样**：定时器配置全对，但 CNT 不计数，永远不会溢出，中断永远不触发。

---

### 5. `TIM_GetCounter(TIM2);`

**作用**：读取当前计数器的值（CNT 寄存器）。
**什么时候用**：主循环里实时显示计数值。
**返回值**：0 ~ ARR 之间的值。

---

## 五、和 6-1 的区别

|  | 6-1 定时器中断 | 6-2 定时器外部时钟 |
|---|---|---|
| 时钟源 | 内部时钟（72MHz） | 外部时钟（PA0 引脚脉冲） |
| 计数频率 | 由 PSC 决定 | 由外部脉冲频率决定 |
| 用途 | 定时 | 计数 |
| 关键函数 | `TIM_InternalClockConfig` | `TIM_ETRClockMode2Config` |
| CNT 变化 | 自动计数 | 每来一个脉冲加一 |

**6-2 的核心是"用外部脉冲驱动计数器"**，而不是用内部时钟定时。这个实验为后面学**编码器接口**打基础。

## 六、踩坑记录

### 错误 1：`CNT` 和 `Num` 都不变

**原因**：
- PA0 没有接收到脉冲信号。
- 信号源没有共地。
- `TIM_ETRClockMode2Config` 配置错误。

**排查**：
1. 确认信号源接在 PA0 上。
2. 确认信号源和 STM32 共地。
3. 用示波器或逻辑分析仪看 PA0 有没有脉冲。

### 错误 2：`CNT` 变化但 `Num` 不变

**原因**：CNT 数到 9 后没有溢出，或者中断没触发。
**排查**：
1. 确认 `TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);` 已调用。
2. 确认 NVIC 配置正确。
3. 确认 `TIM2_IRQHandler` 函数名正确。

### 错误 3：`Num` 和 `CNT` 乱跳

**原因**：信号抖动严重，或者滤波器参数不合适。
**解决**：增大 `TIM_ETRClockMode2Config` 的最后一个参数（滤波器值），比如改成 `0x0F`。

---

## 七、经验总结

1. **外部时钟模式用 `TIM_ETRClockMode2Config`**，内部时钟用 `TIM_InternalClockConfig`。
2. **滤波器参数根据信号质量调整**：信号干净填 `0x00`，抖动严重填 `0x0F`。
3. **`TIM_GetCounter` 可以实时读取 CNT 值**，用于调试和显示。
4. **`TIM_ClearFlag` 用 `TIM_FLAG_Update`**，`TIM_GetITStatus` 用 `TIM_IT_Update`，两者不要混淆。
5. **PA0 作为 ETR 输入，必须和信号源共地**，否则电平没有参考点，读数不稳定。
